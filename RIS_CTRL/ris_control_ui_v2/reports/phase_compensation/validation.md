# QAM相偏补偿参考点验证（2026-11-05）

两种QAM的发送参数页新增默认关闭的“相偏补偿”。每帧按前导码、四角参考点、正式数据顺序编译。256QAM为00 08 88 80，64QAM为00 04 24 20，均为左下、左上、右上、右下。每点使用当前K，整帧循环包含参考点。未启用前导码时从参考点开始。静态核线及停止操作不插入参考点。

## 验证结果

- 52项QAM回归全部通过，覆盖实际Tk、真实Python客户端、本机TCP、真实C解析/驱动及模拟AXI；原码本18项和离线编译8项回归通过。
- 独立400位波形oracle覆盖两种调制、前导码启用/关闭、K=1/3、跨帧重复、旋转及反向极性；四角ID与源星座I/Q坐标相符。
- 上传冻结测试覆盖两种QAM：上传中取消复选框、修改数据/K/前导码均不改变已提交的参考点、正式数据或CRC。所有实际写命令仍来自总下发按钮。
- 未勾选时，命令、表和CRC与原路径一致；选择固定符号、原HEX和文件内容不被四点插入改写。
- 保留4096字节正式数据；参考点导致物理payload超限时使用已有虚拟符号分组，不截断、不补填波形。其他已有容量边界仍生效，失败发生在下发前。
- 导出payload.bin保持正式数据，manifest单独记录参考点与K；离线编译和实时F/E/S/P逐字节一致。
- 两种QAM发送参数页已用真实离线Tk实例截图检查，无回调异常。
- 33个RTL、ARM固件、头文件及配套BIT/XSA/ELF/BOOT等文件的SHA-256与本次修改前一致。没有改变协议、硬件时钟或Flash，不需要重新烧写，也未连接实际板卡下发波形。

产品代码只改GUI、上位机合帧/状态/导出和主机运行的离线编译脚本。后者存于FPGA工程scripts目录，但不属于RTL或ARM固件。
