# 统一400路MT前导码验证（2026-11-10）

统一MT页面增加“启用前导码”和“加载前导码MT表”。仅修改上位机；继续使用既有MTBEGIN / MTSEG / MTSTART协议，未修改或烧写RTL、固件。

- 前导码最多10行，T必须为0；与正式表合计最多512行，并沿用原最小边沿间隔和2048时段检查。
- 编译时拼接前导码与正式MT表，使用同一周期参数；一次播放完成后置低，循环时每轮从前导码开始。
- 未加载正式表时，正式内容为一个默认50%方波周期。取消勾选后恢复原有正式表或FASTTICKS默认方波路径。
- 文件加载、勾选、频率编辑及播放方式选择不产生输出指令；总下发按钮应用完整快照。JSON预设保留合成后的完整表。
