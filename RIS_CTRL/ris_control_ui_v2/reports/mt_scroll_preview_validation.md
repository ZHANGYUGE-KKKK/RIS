# MT完整序列滚动预览（2026-11-10）

统一MT的预览入口改用完整帧预览窗口：波形支持水平滚动条与鼠标滚轮，参数表支持垂直滚动，选中行可定位并高亮对应周期。显示当前可见周期范围。启用前导码时，预览包含前导码和全部正式MT行；预览保留打开时的配置快照。

64QAM和256QAM的前导码MT表原本已载入全部行并提供垂直滚动，本次也核对了两者第10行可达。未更改前导码行数、MT容量、编译规则、总下发流程、原版控制台、固件或RTL。

验证共13项通过：原MT编译测试10项、新预览测试3项。新测试覆盖完整512行及末尾波形的独立时间域检查、表格末行、滚轮、选行定位、单周期/全0/全1/一次结束置低、前导码与正式表合并、预览快照、两种QAM前导码表，以及预览不建立连接或输出指令。

新测试日志：[mt_scroll_preview.log](mt_scroll_preview.log)。另以960×600和720×480窗口检查末尾滚动、参数列及帮助文字完整显示。所有验证均在本地完成，未连接板卡。
