# QAM PWM频率与状态面板验证（2026-11-06）

两种调制共用按slice校验的频率规划。统一64 slice全局上限约161.638 kHz；256 slice上限约40.409 kHz。加载码本保留输入频率，不自动降低；超限时阻止总下发并保持原输出。

- 新256QAM 64slice码本已通过文件校验、播放表编译及GUI→本地TCP→现有C协议/驱动→AXI模型完整链路，160 kHz、前导码、相偏补偿四点和00/88/FF正式数据均正确配置。
- 从该码本切换到256slice码本后保留160 kHz，界面提示超限；未产生新的写命令，运行CRC保持不变。
- 星座阶数与计时模式已分开。板端旧字段qam_order表示计时模式，不能据其猜测星座阶数；有CRC匹配快照时显示对应调制，否则显示QAM。
- 导出配置和实时上传使用相同计时；保留旧ZIP及旧整数片接口兼容性。低频自动使用现有整数片计时，两种调制遵循同一规则。
- 状态区分配左侧空余宽度，长标题、详情、确认信息及下发摘要自动换行并增高；1460与1180像素窗口均无面板内部裁切。

共71项不同测试通过：频率规划与导出6项，GUI及完整软件链路11项，码本/波形/协议回归46项，离线编译器8项。GUI链路日志额外包含5项重复的频率测试，统计已去重。日志路径及源文件哈希见validation.json。

初次回归期间原256slice码本文件改名，旧默认路径导致加载断言失败；引用更新后重新验证。此前按调制阶数区分频率的中间规则已被本次统一slice规则替代。旧的中间日志仅保留排查记录，不作为最终验收依据。
