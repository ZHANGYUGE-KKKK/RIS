# 64QAM 控制与160 kHz播放

入口：主页面选择“MT时域控制”，控制类型选择“400路独立 / 64QAM”。统一MT、256QAM、64QAM只显示当前选中的配置页面，草稿分别保存于各自界面实例；切页不改变输出。方向、状态极性及400路FPC接线映射沿用共同的全板设置。

从工程根目录直接进入并加载默认码本：

```bash
./RIS_CTRL/ris_control_ui_v2/start_gui.sh --qam64
```

默认码本读取 `QAM_RULES/64QAM/ris_64qam_64slice_codebook`，参数为160 kHz、64片、K=1。不会复制或覆盖该码本；导入ZIP/目录均检查文件SHA-256、IIIQQQ标签、Gray坐标、400路几何、脉冲参数及全部4096幅源图案。64QAM页面拒绝256QAM码本，反之亦然。

## 操作

1. 点击“加载本项目0°码本”，或导入64QAM目录/ZIP。
2. 核对“全板设置 → QAM方向与极性”和FPC映射；继续使用已完成实物核对的设置。
3. “发送参数”选择数据源，填写K、整帧循环及前导码。“输出PWM频率”填写160，单位选kHz。
4. 点击右上角总“下发指令”，读取板端能力后上传、检查CRC、预检并开始播放。

数据源与256QAM一致，但每字节只存一个00–3F符号ID。高3位是I的Gray标签，低3位是Q的Gray标签，各轴Gray解码后电平为 `2*n-7`，按 `7*sqrt(2)` 最大角点归一化。有效信息为低6位，高2位必须为0；不会截断高位，也不会自动把任意二进制文件拆成6位流。例：HEX序列 `00 1B 3F` 对应3个符号。测试序列为00–3F。

固定符号使用预览区选中的HEX标签；HEX输入只在“十六进制字节序列”数据源下使用。星座/PWM/阵列是本地码本预览，不是板端电压或接收星座回读。

K只作用于数据：K=1时每符号6.25 µs，符号率160 ksymbol/s、数据段裸比特率960 kbit/s；K=3时每符号18.75 µs。前导码每行仍是一个PWM周期、延时必须为0、最多10行，每帧循环都先播前导码再播数据。前导码与QAM使用同一播放器、同一周期计时，转接没有电脑启动间隙。

## 时钟与边沿量化

SHCP仍为100 MHz，突发中每次8个脉冲，高低各5 ns。AXI仍100 MHz，内部波形引擎仍300 MHz。未提高FPGA或595时钟。

160 kHz对应6.25 µs，恰好为1875个300 MHz tick。64片等分的理想片长为97.65625 ns，不能精确对应整数tick。因此上位机将每个源边沿q编译到：

```
edge(q) = round_half_up(q * 1875 / 64)
```

每片为29或30 tick，即96.666…或100 ns；每周期共45个29-tick片、19个30-tick片，严格合计1875 tick。每个PWM周期重新对齐原点，不积累相位漂移。相对源码本的单个边沿误差不超过半个tick（约1.667 ns），脉宽由两个量化边沿之差确定。若要求每片在电气上完全等宽，需要另外的时钟方案；本实现保留原时钟并明确显示边沿量化方式。

400路空间图案不变。只有边沿时刻按上述规则量化。前导码、K次重复、下一符号和下一帧保持相同周期边界。源码本约1.0673%模型均衡EVM是源文件模型值，没有包含本次边沿量化、驱动、RIS响应和接收机影响。

## 配套硬件与协议

旧 `QBEGIN` 整数片接口、200 ns最小片长、CRC及查表逻辑保留兼容。当前GUI对两种QAM共用边沿计时，上限由slice数决定，详见[统一PWM频率设置](qam_pwm_frequency.md)。新增64QAM使用相同的图案字典、RLE事件、符号描述及payload查表结构；新命令为 `Q64BEGIN 1 K L loop`，L和事件持续长度在此模式下以300 MHz tick为单位。默认物理L=1875。64个源符号后，其余硬件描述项别名到有效符号00，供既有256项预检流程使用；当前GUI使用QPR1独立前缀，不占用QAM索引及正式payload。需配套本次RTL及固件；旧Q64BEGIN仍保留兼容。见[独立前导码](qam256_preamble.md)。

新增寄存器：MODE 0x250（写0为旧模式，写64为边沿tick模式；读256/64），64QAM能力ID 0x254（0x51413634），最短事件0x258（29 tick）。配置及表在预检/运行/保持占用期间仍冻结。最短模式的STCP脉宽至少2 tick（约6.667 ns，仍需按实物器件核对），停止完成当前8位突发和有效锁存后保持400位。29-tick以下事件会在启动前拒绝。

CRC仍覆盖7个小端32位头字段和F/E/S/P；64模式额外在头字段之后、F块之前加入小端32位值64，避免两种计时语义混淆。固件能力新增 `qam64_supported`、`qam_order`、`qam64_min_event_ticks`，原QAM1能力字段保持原含义。GUI在发送任何写指令前检查64QAM能力，旧固件不会收到半套新上传。

配套源代码及BIT/XSA/ELF位于 `FPGA/ris_qam_backend`。新功能需要新BIT与ELF配套加载；本次开发不自动连接、下载或烧写实际板卡。Flash旧启动包保持独立，不能将旧ELF与新BIT混配。

验证记录见 `FPGA/ris_qam_backend/reports/qam64/validation.md`。

界面直接设置输出PWM频率，例如78.125 kHz；程序自动换算并显示实际值。该计时模式名不代表调制阶数；调制阶数由匹配CRC的上传快照确认，未知时显示QAM。单个编译周期上限65535 tick，可用频率范围见[统一PWM频率设置](qam_pwm_frequency.md)。
