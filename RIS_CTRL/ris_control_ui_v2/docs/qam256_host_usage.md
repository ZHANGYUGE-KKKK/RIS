# 256QAM上位机使用说明

已实现上位机配置、预览与实时QAM1上传播放，保留四大功能分类和统一下发入口。实时播放、配套BIT/ELF与时序选择先看 [完整链路使用说明](qam256_end_to_end.md)。

## 打开

运行 `/home/wenhan/PROJECTS/RIS/RIS_CTRL/ris_control_ui_v2/start_gui.sh`，在主下拉框选择“MT时域控制”，再在“控制类型”中选择“400路独立 / 256QAM”。

也可直接运行：

```bash
/home/wenhan/PROJECTS/RIS/RIS_CTRL/ris_control_ui_v2/start_gui.sh --qam
```

这会打开256QAM页面并加载随副本提供的0°码本，不连接板卡、不下发图案。`--codebook /path/to/码本目录或ZIP` 可导入其他同格式码本。仍支持原有的 `--mt`、`--patterns`、`--mapping` 和 `--mapping-file` 等参数。

## 导入与预览

“加载本项目0°码本”使用 `../../../QAM_RULES/256QAM/ris_256qam_256slice_codebook_0deg.zip`。原始码本统一保存在 `QAM_RULES`，控制台读取该数据。也可导入文件夹或ZIP，支持ZIP中单独一层或多层码本根目录，不在磁盘上解压。

导入会检查：

- 6个文件的SHA-256完整性与清单唯一性；
- 20×20几何、索引、方向、256个Gray符号及归一化坐标；
- 帧长、位序、L/K/频率和速率字段的一致性；
- 每个方向、每个符号、每个时间片的二进制图案与p/r脉冲参数是否完全一致。

格式错误、损坏、超出64 MiB、重复ZIP条目、越界路径和符号链接等输入会被拒绝，保留之前已经加载的码本和参数。

“星座 / PWM / 阵列预览”包含三个联动视图：

1. **目标星座**：蓝点是文件中的目标256QAM符号，橙点是所选符号；点击点可选择。没有把模型或目标点伪装成接收测量。
2. **单元PWM**：显示码本状态C的两个PWM周期，标出当前时间片，显示所选单元的M和T。行列选择为1–20，单元id为0–399。
3. **阵列**：选择时间片q（从0开始）查看整板状态。点击格子改变所选单元，联动PWM。方向/极性未确认时显示码本空间状态；确认后显示RIS实物方向下的驱动高低预览，仍不是实测电压。

小窗口内图表保持可读尺寸，使用预览区右侧滚动条查看完整内容。参数和兼容性页面也支持滚动。

## 发送参数

“发送参数”支持固定符号、十六进制序列、二进制文件和00–FF测试序列。

- 固定符号使用预览区的HEX字节。
- HEX序列可写为 `00 3F FF`、`003FFF` 或以逗号/分号分隔，必须是完整字节。
- 二进制文件将每个字节视为一个IIIIQQQQ Gray标签，不按文本字符解析。加载后使用内存快照；文件后来被改动时，当前配置不会偷偷改变，需重新加载。
- 预览/来源ZIP数据量上限1 MiB，实时QAM1下发另限1–4096字节；超出会拒绝，不截断。空文件、奇数字符HEX等输入会被拒绝。
- K是每个符号重复的PWM周期数，范围1–1,000,000，默认读取码本中的3。
- 循环选项作用于整个发送数据序列；取消则为一次播放配置。

页面直接设置输出PWM频率，并显示实际可实现频率、符号率、裸比特率和一遍时长。程序自动换算板端整数计时，超出支持范围时拒绝下发。L及400路脉冲的片位置保持不变，详见[统一PWM频率设置](qam_pwm_frequency.md)。

## 方向、极性与静态核线

进入“全板设置 → 256QAM方向与极性”，选择原向/旋转/镜像关系和状态1对应驱动高还是低。界面显示码本三个角到RIS行列的转换结果，供按实物BIAS标记核对。

核对后勾选实物确认，再点击“保存已核对设置”。设置只写入本副本的 `qam/settings.json`，不改变输出；修改方向或极性后，确认状态会自动撤销。默认未确认时，不开放静态码片应用或控制器播放包导出。

静态核线步骤：

1. 在全板设置中加载完整400路FPC—RIS映射，并配置/核对方向与极性。手动映射仍需满足原来的实测确认规则。
2. 回到256QAM预览，选择方向、符号、时间片。
3. 在页面底部选择“静态码片核线”。此操作只配置。
4. 连接板卡，点击右上角“下发指令”。程序在该时刻将空间图案转换为595芯片/Q位序，通过原FRAME指令应用。
5. 收到正确板端应答后，状态屏显示“256QAM静态码片”，说明当前是静态保持。继续编辑/切页不会更新实际输出。

停止也需在底部选择“停止 / 保持”，再点击总按钮。停止不要求已经载入码本。

## 离线发送配置包

“导出发送配置包”把来源信息、当前输出PWM频率、数据与映射编译成ZIP快照；`output_timing`记录实际输出计时。它不连接板卡、不停止当前运行、不发送命令。导出前同样要求完整映射和已核对的方向/极性，不允许覆盖源码本。

| 文件 | 含义 |
| --- | --- |
| `manifest.json` | 包格式、来源指纹、方向、极性、映射哈希、PWM/L/K、循环、时长和数据布局。明确标记`transport_ready=false`。 |
| `source_metadata.json` | 原码本模型参数及说明。 |
| `mapping.json` | 下发配置对应的完整FPC映射快照。 |
| `patterns.bin` | 去重后的板端图案，每帧50字节，按芯片字节/Q0–Q7排列。 |
| `events.bin` | 每段4字节：小端uint16图案id、小端uint16持续片数。 |
| `symbol_index.json` | 256个符号各自的首段索引和段数，每个符号从q=0开始。 |
| `payload.bin` | 待发字节流。每个字节对应的PWM周期由播放器重复K次。 |
| `SHA256SUMS.txt` | 包内全部数据文件的完整性校验。 |

当前示例导出1119幅图案和26,103个时段，图案与时段裸数据合计160,362字节。测试已逐帧还原，确认所有65,536个源时间片经FPC映射转换后的状态一致；去重与合并不会删除短脉冲。

## 与当前板端的关系

独立QAM播放器RTL、ARM驱动与TCP协议集中在 [FPGA板端工程](../../../FPGA/ris_qam_backend/README.md)。GUI底部“连续播放”通过总按钮完成能力检查、完整分块上传、CRC校验和启动；“静态码片核线”继续使用FRAME。旧固件只有统一MT能力时，QAM连续播放仍会拒绝。

该256片码本的1 MHz来源频率仍超出当前硬件能力。当前两种QAM共用边沿计时，256 slice上限约40.4094828 kHz，64 slice可设置160 kHz；源包的约0.3143%模型均衡EVM不代表实际测量。具体步骤与速率见 [完整链路说明](qam256_end_to_end.md)。
