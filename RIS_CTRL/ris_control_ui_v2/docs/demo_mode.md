# 演示模式与统一JSON预设

主页面“功能”下拉菜单新增“演示模式”。页面固定十行，每行左侧为“选择该模式”，右侧初始为“请加载预设”；成功载入后，右侧显示文件名。被选中的行以蓝色按钮标识。

## 使用步骤

1. 先到任一原有功能页完成配置，选好希望下发的操作。
2. 点击功能菜单右侧的“导出当前配置”，保存为JSON。导出不要求连接板卡，也不会更新当前输出。
3. 切换到“演示模式”，分别点击各行右侧按钮，加载需要的JSON预设。
4. 需要切换时，点击对应行左侧“选择该模式”。右上角会显示待下发摘要。
5. 点击右上角总“下发指令”，等待板端确认。

右侧加载只负责载入文件，不会自动选择或下发。左侧选择只更新待下发内容；正在运行的输出、图案列表和正在上传的内容均保持原样。只有总按钮应用新预设。

重新加载当前选中行时，会取消这行的待下发选择，要求再点左侧选择。文件无效则保留之前有效的预设与选择。

“选择停止 / 保持”同样只设置待下发操作，仍需点击总按钮。上传过程中可这样取消上传；总按钮会变为“取消上传并停止”。

## 支持的内容

| 功能 | 预设保存内容 |
| --- | --- |
| 全板控制 | 全0/全1、停止保持、慢速循环、硬件方波、单元BIT、单芯片或5片组字节操作 |
| 统一MT | 完整MT表、输出频率、一次/循环，恢复时重新生成同样的硬件时段 |
| 图案切换 | 当前静态图案；或完整播放列表、每项图案与停留时间、顺序/循环/往返/随机方式 |
| 64QAM / 256QAM | 编译后的完整码本表、正式数据、实际PWM计时、K、循环、前导码、相偏补偿、方向等元数据和CRC；也支持静态码片 |
| 全板设置 | 输出使能/禁能，以及已选中的接线测试动作 |

文件保存的是当前待下发操作。单元、芯片、组控制仍按原功能只修改对应输出，其余保持；不会把它们扩展成新的全板图案。纯本地设置、接线标定进度、通信地址和编辑历史不属于输出预设。图案库JSON、映射JSON和原QAM离线ZIP仍保留各自用途；演示页需要统一格式的预设JSON。

## 文件与恢复

所有预设使用`format: "ris-control-preset"`、`version: 1`。文件包含操作类型和说明，以及运行所需的参数或表数据。QAM和图案预设无需再次读取原始码本、二进制数据或图案库；MT表也包含在预设内。

十行加载内容会保存在本控制台`presets/demo_slots.json`。这是经过校验的内容快照，移动、删除或修改原JSON不会暗中改变已加载的预设。下次启动恢复十行，但不自动选择、不自动连接、不自动下发。若确实要应用修改后的原文件，应重新点击该行右侧加载。

修改FPC映射、QAM方向或极性后，已有预设仍保持导出时的输出。要使用新设置，需重新导出并加载；演示预设不会覆盖其他页面的草稿或当前映射。

每份预设上限2 MiB。加载时校验格式、参数、图案/事件容量、完整QAM描述周期与CRC。板端能力仍在总下发时检查，不支持的预设不会先停止原输出。图案列表沿用原来的电脑端调度，需要控制台及连接保持运行。

本功能只修改上位机，不增加板端协议。QAM预设继续需要相应QPR1配套BIT和固件。

可直接使用[示例预设](../examples/demo_presets/)中的全0、全1、停止及统一MT示例。启动后直接进入演示页：

```bash
./start_gui.sh --demo
```
