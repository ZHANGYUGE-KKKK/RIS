# QAM独立前导码与完整符号表

2026-11-09起，控制台、ARM固件及RTL使用配套QPR1扩展。前导码及相偏参考点拥有独立播放描述，不再与256项QAM符号表争用索引。需要更新本次配套BIT和ELF或Flash启动包。旧板端会在能力检查时被拒绝，此时不会先停止原输出。

## 操作

在“MT时域控制”中选择256QAM或64QAM，进入“发送参数”：

1. 导入对应码本，设置最终输出PWM频率、正式数据、K和整帧循环方式。
2. 点击“加载前导码MT表”，载入1–10行MT表，延时T必须为0。
3. 按需启用“相偏补偿”。256QAM四点为`00 08 88 80`；64QAM为`00 04 24 20`。
4. 点击右上角总“下发指令”，一次上传并启动。

编辑、加载、清除、切页和导出均只改变草稿。上传使用开始时的不可变快照；后续编辑不会混入已经开始的上传。

每帧顺序为：**前导码一遍 → 相偏参考点（若启用）→ 正式数据**。整帧循环时每次重新从前导码开始。前导码每行占1个PWM周期；每个参考点和正式符号均占K个周期。单次完成后保持最后输出，停止及取消上传也由总按钮应用。

## MT表和周期

```text
(25,0);
(50,0);
(75,0);
```

沿用`(M,T);`百分比格式及原MT注释。M是400路同时输出的电气高电平占比，T必须为0。0%全周期低，100%全周期高；QAM状态极性只作用于后续QAM波形。

占空比先按码本slice网格量化：高电平片数为`round_half_up(M×slice数/100)`。高速模式再把片边界舍入到300 MHz整数时钟，每个PWM周期首尾边界保持一致；若非恒定脉冲量化后消失或短于29 tick，会拒绝该配置。

前导码和QAM由同一个FPGA播放器及事件定时器执行，没有电脑切换模式产生的启动间隙。

用户原配置：256QAM、64 slice、120 kHz、3行前导码、相偏补偿启用、00–FF正式数据、K=1：

```text
25%统一方波 → 50%统一方波 → 75%统一方波
→ 00 → 08 → 88 → 80
→ 00 → 01 → … → FE → FF
→ 下一帧重新从25%统一方波开始
```

每项一个完整PWM周期。一帧`3+4+256=263`周期，约2.191667 ms；无须缩短数据或删除参考点。

## 容量和分工

- QAM符号表：固定256项；64QAM未用项指向符号00。
- 独立前缀：最多14项，容纳10行前导码及4个参考点；参考点直接引用原QAM事件。
- 正式数据：1–4096字节，前导码和参考点不占用这些字节。
- 图案和事件仍共享：2048幅图案、32768个事件；前导码通常只增加全0/全1图案及每行1–2个事件。
- K为1–1000000，由硬件计数，不展开为K份数据。

不存在“整帧最多256个PWM周期”的要求。仍会检查实际图案/事件容量及最短事件间隔。频率上限只由slice数和板端时序决定，与QAM阶数无关。

上位机编译、计算CRC，ARM按顺序上传及核对CRC，RTL预检完整的QAM表与前缀后播放。CRC包含前缀配置及内容，是传输校验字段，不是额外空口符号。

导出ZIP保留正式payload、前导码、相偏配置、输出频率及`independent_prefix: true`。离线编译器生成相同F/E/S/B/P内存，上传文件不含START。历史ZIP继续保留旧编译方式；当前GUI下发使用QPR1。
