# QAM输出PWM频率设置

256QAM与64QAM都在“发送参数”中直接填写“输出PWM频率”，单位可选Hz、kHz、MHz。播放时序模式与低速核线片长不再作为界面参数。

两种调制使用相同的计时规则。频率上限由每周期slice数和现有板端时序能力决定，与星座点数量无关。界面统一以64 slice设置全局最高频率，约161.637931 kHz；加载更多slice时会进一步检查当前频率。

| 每周期slice数 | 两种调制共同的PWM频率上限 | 160 kHz |
| --- | --- | --- |
| 64 | 约161.637931 kHz | 支持 |
| 256 | 约40.4094828 kHz | 超限，禁止下发 |

上限按现有300 MHz计时、最短29 tick及每周期slice数计算；仍保持100 MHz SHCP，不提高FPGA或595时钟。少于64 slice的码本仍受统一全局上限限制。程序自动使用已有边沿计时能力；更长的低频周期自动使用已有整数片计时，调制阶数不参与选择。实际输出频率按最近可实现计时量化，并在页面显示。

加载、切换码本时保留用户填写的频率并重新校验，不自动降低频率。超出当前码本能力时仍可预览，状态保持原输出；频率提示和总按钮旁摘要说明当前slice数与支持范围，无法下发。修改频率后重新校验，合格后才允许总下发。

`QAM_RULES/256QAM/ris_256qam_64slice_codebook`可在256QAM页面直接通过“导入码本目录”加载，并在本次统一计时实现中按160 kHz播放。仍使用256个符号、00–FF标签和相偏补偿四点`00 08 88 80`。64 slice不代表64QAM。

原256片码本已更名为`ris_256qam_256slice_codebook_0deg.zip`，默认加载入口已更新；64片版本通过导入选择。默认频率草稿沿用256QAM页面19.53125 kHz、64QAM页面160 kHz，用户可直接修改；这些是起始配置，不是按调制阶数划分的频率上限。

前导码、相偏补偿四点与正式数据始终共用设置的PWM周期及周期边界；K仍表示每个QAM符号重复多少个PWM周期。点击右上角总“下发指令”后，程序才冻结并上传本次配置。上传或播放期间继续编辑不改变本次快照。

“导出发送配置包”记录同一频率设置：`manifest.json`的`pwm_hz`仍是来源值，`output_timing`保存用户请求频率与实际输出计时。`one_pass_seconds`按实际输出频率计算。配套离线编译器直接使用`output_timing`，无需另填片长；旧ZIP沿用原有编译方式。

板端旧命令`Q64BEGIN`和`qam_order`中的64实际标识边沿计时模式。该模式支持256项符号索引，不能据此判定星座点数。控制台用与板端CRC匹配的上传快照显示64QAM或256QAM；无法确认时显示QAM，避免误报调制类型。

本次复用已烧写的边沿计时能力，仅修改上位机和离线编译工具。无需重建RTL、固件或重新烧写。

状态面板利用左侧空余宽度；状态标题、详情、板端确认信息和下发摘要均随宽度换行，顶部区域随内容增高。
