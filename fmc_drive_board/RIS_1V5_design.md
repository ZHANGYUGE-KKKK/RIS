# 外部电池 1.5 V 接口

2026-09-28：原 `RIS_1V5` 页已改名为 `BATTERY_GND`，板上不再放置 TPS51200、REF3025、1.5 V 反馈、四路 0 Ω 分配或 1.5 V 去耦电路。RIS 的 1.5 V 由外部干电池组提供。

## J3 电池盒地接口

| 项目 | 实现 |
| --- | --- |
| 器件 | J3，`HDR-M_2.54_1x4P`，LCSC `C9900236824` |
| 封装 | 1×4 通孔排针，2.54 mm 间距 |
| 针脚 | 1、2、3、4 全部连接到板上 `GND` |
| 用途 | 电池盒负极可接入任意一个或多个 J3 针脚，四针并联降低接触和线缆电阻 |
| 电池正极 | RIS 单元侧的 1.5 V 正极连接器和针序尚未确定，未在本板加入正极电源网络 |

J3 四针是同一个 GND 网络，不是四路独立电源，也不提供 1.5 V。外部电池的电压、容量、保护和上电时序由 RIS 单元及其电池盒负责。

## 当前联锁

U22 现在只监测 `VCC33_LOCAL`。它的 MR# 接 `VADJ`，不再连接任何 1.5 V PGOOD；U23 继续生成 `OE_SAFE_N`，当本地 3.3 V 无效时将 18 个移位寄存器输出置高阻。FMC D18 继续输出 `PWR_READY`。

## 验证状态

通过嘉立创EDA实时 API 核对：

- BATTERY_GND 页只保留 J3，四个 J3 针脚均有 GND 导线连接。
- 全部页面没有 `RIS_1V5` 网络，也没有 U19、U20、TPS51200 或 REF3025 器件。
- PWR_CTRL 的 U22 MR# 已连接 `VADJ`。
- PWR 页 18 片移位寄存器的本地去耦已统一使用 `VCC33_LOCAL`。
- DRC API 返回 `warn: 174`，未返回 error；警告明细仍需在嘉立创EDA界面逐项检查。

外接 12 V 和 3.3 V 降压设计见 [EXT_12V_design.md](EXT_12V_design.md)。
