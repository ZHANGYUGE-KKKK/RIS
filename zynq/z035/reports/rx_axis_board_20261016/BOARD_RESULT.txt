最终硬件结果（第二次运行）：
  普通接收观察 5.017117 s，有效 IQ=0，50/50 窗口未通过。
  FPGA DATA/FRAME 32x32 网格加七路单独 32 taps，共 1248 点，PN 通过 0 点。
  PN 持续观察 5.015779 s，有效 IQ=0，FRAME 没有锁定。
  恢复普通接收后观察 5.014932 s，有效 IQ=0，FRAME 仍未锁定。
  独立 ADI 测频器：普通接收 169.713 MHz，PN 178.510 MHz，恢复后 171.118 MHz。
  修正后的短子窗口计数均值：170.880 / 178.337 / 170.316 MHz。
  PLL 只读检查 20/20 通过；GPIO 最终为 0x01（READY=1，FRAME_LOCKED=0），ARM=0。

上述 MHz 是 FPGA 内部识别到的时钟边沿率，不是示波器对芯片引脚的测量。
当前模式理论 DATA_CLK 应为 4 x 15.36 = 61.44 MHz；实际接收到的数字时钟
明显不符合这一关系，而且随测试数据源变化。当前没有足够证据确认异常发生在
AD9361 输出、实物连接/端接、输入波形，还是受异常输入影响的接收/观测路径。
不能据此认定 AD9361 芯片损坏，也不能宣布重写模块已经通过板级验收。

原来的 100ms 单次 24bit 模差在异常高频下会多次回绕，第一轮的 2~21 MHz
结果不可作为真实边沿率。驱动已改成约 1ms 子窗口累加，并用 64bit CPU 时间
保证每个观察窗口至少 100ms。模型验证覆盖 61.44/245.76/500 MHz。
第二轮仍出现个别 FRAME 计数不连续，导致单个累计窗口的表观 FRAME 频率异常；
不将该值解释为物理 FRAME 频率。无有效 IQ、未锁定和独立时钟测量的结论不变。
PN 错误锁存或 frame_fault 为零也不表示通过：解帧从未获得有效数据/稳定锁定。

最终另抓取三份 4096 点 ILA：ila_final/。原始记录显示观测 FIFO 持续有效、
RX 序号跳变、没有 sample_valid/FRAME lock；结论与软件一致。
