# 256QAM前导码MT表

实现采用上位机统一编译，继续使用已经烧写的QAM1播放器。前导码和QAM被编为同一条图案/时段序列，一次上传、一次START，播放过程不经过电脑切换MT/QAM模式。RTL、固件和Flash镜像均不需修改。

## 操作

重启新版控制台，进入“MT时域控制 → 400路独立 / 256QAM → 发送参数”。

1. 配置码本、发送数据、数据K和播放片长。
2. 点击“加载前导码MT表”，载入最多10行的MT文本；成功后自动勾选“启用前导码”。
3. 查看表格内的输入占空比和实际占空比。前导码继承QAM的PWM周期，不另设频率。
4. 选择底部“连续播放”，点击右上角总“下发指令”。

载入、清除、启用/停用前导码和修改配置均只改变草稿；需要再点总按钮才应用。文件载入后保存内存快照，修改磁盘文件不会偷偷更新当前配置。错误表保留之前的有效配置。

勾选“循环整帧（含前导码）”时，每一帧都按“前导码一遍 → QAM数据一遍”重复。取消勾选则整帧执行一次，之后保持最后图案。STOP与上传取消仍通过总按钮。

## 格式与时序

示例见 [qam_preamble_mt.txt](../examples/qam_preamble_mt.txt)：

```text
(25,0);
(50,0);
(75,0);
```

沿用原MT的`(M,T);`百分比格式，允许空行和`#`/`%`注释。这里所有T必须严格等于0；一行占一个完整PWM周期。M表示400路驱动高电平占比，前导码在周期起点同时置高、达到脉宽后同时置低。0%全周期低，100%全周期高。前导码按电气电平定义，QAM的状态极性设置只作用于后面的QAM码片。

前导码与QAM使用相同的时间片网格。L=256时占空比按`round_half_up(M×256/100)`量化：例如20%对应51片，即19.921875%，80%对应205片，即80.078125%。界面显示实际值；量化后脉冲或低电平消失的非恒定输入会拒绝。

每行前导码只占1个周期，K只作用于QAM数据。例：3行上述前导码，数据`3F A5 00`，K=3，200 ns/片：

```text
25%统一方波 → 50%统一方波 → 75%统一方波
→ 3F波形×3周期 → A5波形×3周期 → 00波形×3周期
→ 下一帧重新从25%统一方波开始
```

基础PWM周期始终为256×200 ns=51.2 µs。前导码153.6 µs，QAM部分460.8 µs，一帧614.4 µs。硬件锁存的流水线延迟为统一常量；前导码到QAM、QAM到下一帧前导码的间隔由同一硬件计时器保持，没有软件启动间隙。

## 合帧方式与容量

现有播放器一次只能使用256项符号索引，每项须有相同的片数。上位机把一个或多个完整PWM周期编成“虚拟符号”，用既有8位索引串成一整帧。QAM数据需要的K次重复在这条索引序列中体现，板端统一以K=1执行；不会向接收端额外加入补齐周期或符号。

编译器优先保留每项一个PWM周期。较长帧可将若干完整周期合成一项，项长度不超过65535片，并保证一整帧刚好由完整项组成。所有256项索引仍满足现有硬件预检，未用索引指向有效的同长度条目。

合帧仍受2048幅图案、32768个时段、256项索引和4096字节板端索引序列限制。数据长度、K和占空比组合都会影响占用；不能保证任意4096字节数据与前导码都能容纳。容量不够时在发出任何输出指令前拒绝，并提示缩短数据或减小K。未启用前导码时继续使用原QAM编译方式。

状态屏在本次已确认配置的CRC匹配时显示基础PWM、前导周期数、QAM数据量和逻辑K；不伪造当前正在前导码或QAM的实时位置。仅凭重新连接后的寄存器无法还原合帧结构，此时显示板端播放器周期参数。

“导出来源配置包”也保存`preamble_mt.txt`及其量化配置，不省略前导码。离线MMIO编译器可编译该包，改速仍需显式`--slot-ticks 60 --retime-for-bench`。导出继续保留源码本时序，不包含GUI的低速改速设置。
